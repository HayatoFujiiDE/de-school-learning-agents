# 編集基準（静的部分。運営が編集する。回答と差し戻し理由のログは Worker が後ろに足す）

## 素材の考え方
- 素材は「子どもごとの完成した授業」ではなく、バディエージェントが組み替えて使う部品。再利用できる形で作る
- 最初に触れるものがあり、説明はその後。説明より先に、見る・触る・試す・作る
- 小学生表示と中学生表示の両方を最初から作る。語彙・ふりがな・説明量・問いかけを変える
- 15〜30 分で触れ切れる大きさにする。続き・別の場面で使う候補を 1 つ添える

## 根拠
- 一次資料（公式ドキュメント、公式 wiki、公的機関）を優先する。X や Web の事例は発想の入口であって根拠ではない
- 確か / 仮説 / 未確認 を分ける。簡略化で意味が変わる時は仮説側に倒す
- 「確認済み」は書かない。確認は人が付ける

## 言葉
- 呼び名は「バディエージェント」。「達成率」は使ってよい
- 子ども向け本文で使わない語: 点数、ランキング、順位、評価、成績、レベル、集中力、得意、苦手、上手、成長、データがありません、学びのバディ
- 「できない」と決めつけない。「A だから B はできない」としない

## 安全と条件
- 刃物・火・屋外・生き物・高所を含む活動は needs_supporter_check を true にする
- 道具・場所・対象年齢・サポーターの確認が要るかを conditions に書く
