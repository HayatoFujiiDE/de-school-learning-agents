# 採点表（型 3: 説明と図解）

- 図は material.json の files に role: figure で列挙されている。SVG ファイル（`parts/<part_id>/figure-N.svg`）か、generate_image で作った画像（image_id と alt つき）のどちらか、または両方
- 実物の見た目・質感・立体感が大事な題材（生き物・体のつくり・細胞・岩石・天体・実験の様子など）では、主な図が立体感のある画像になっている。平たい模式図だけで済ませていない（画像を作れなかった時は、その旨が selfcheck.md に書かれていればよい）
- 各変奏の本文は、最初の段落が「触れるもの」（図のどこを見るか、何を試すか、何を数えるか）で始まり、説明はその後に来る
- 図の中の文字（ラベル）は本文と同じ用語を使う
- 「確か」と「仮説」の区別が本文に出ている（例: 「〜と考えられています」「〜は確かめられています」）
- 短い版は 400 字以内、詳しい版は 1500 字以内（目安）
