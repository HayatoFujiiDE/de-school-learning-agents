題材: Minecraft **Java 版**のレッドストーン回路の基本。信号が「ある / ない」の 2 状態で伝わること、レッドストーンダスト・トーチ・リピーター・レバーの役割、NOT 回路（トーチで信号が反転する）までを扱う。

版の前提（いちばん大事）:
- うちで使っているのは Java 版です。Java 版の最新の正式版を基準にしてください。最新の正式版は https://piston-meta.mojang.com/mc/game/version_manifest_v2.json の latest.release で確かめます（2026-11-07 時点では 26.3）。
- material.json の conditions.tools に "Minecraft Java 版 <版>" と書きます。子ども向けの本文（body.md と、あれば play.md）に「この説明は Java 版 <版> のものです。スマホや Switch の統合版では、少しちがうことがあります。」の 1 文を入れます（版を書かない本文は機械検査で差し戻しになります）。
- 情報は Java 版と統合版（Bedrock Edition）を分けて集めてください。minecraft.wiki では Java 版の記述の箇所だけを引用し、「Bedrock Edition」「統合版」「BE」の箇所を根拠にしないでください。ページの「歴史」「History」の節で、引く仕様が今の版で変わっていないことを確かめてください。統合版の仕様は本文に書きません。
- 古い情報を根拠にしないでください。動画を使う時は youtube_info の published（公開日）が 3 年以内の、Java 版の動画だけにします。合う動画が無ければ動画なしで作ります。

作るもの: 型 3（説明と図解）と型 4（動かせるもの）。動かせるものは、レバーを押すとダストが光り、トーチを挟むと反転する様子を 1 ファイルの HTML で再現する（外部ライブラリなし、操作 1 つで見た目が変わる）。本文は、動かせるものを先に触ってから読む流れで書く。

見た目（ふじさんの差し戻し。前の版への指摘の原文: 「レッドストーンダストが本物のダストとデザインが乖離していてわかりにくい。他の画像も同じ」）: 図（figure）も動かせるもの（app.html）も、ダスト・トーチ・リピーター・レバー・ブロックは Java 版の実際の見た目（色・形・向き・置かれ方。ダストは地面に置いた赤い粉の線で、信号が通ると明るい赤に光る。トーチは棒の先に赤い光）に寄せて描く。丸や矢印だけの抽象的な記号にしない。

本文: 中学生向けに 1 本（小学生へはバディが易しくするので、小学生向けの別の本文は作らない。易しくすると意味が変わる事実だけ、claims に小学生向けの言い方を添える）。最初の段落は手を動かす文で始め、「やってみる → 気づく → ことば」の順。信号強度 0〜15 と減衰は、ダストを伸ばして消えるところを数えてから言葉にする。

面白さの芯（子どもには見せない。バディと読み手係が使う）: 「トーチを間に挟むと、レバーを入れた時に消えて、切った時に光る」— 信号が「ない」ことも 1 つの状態で、それを使うと「逆」が作れる、という気づき。

問いの種: 2〜5 件。答えは書かず、答えになる主張の id を付ける（例: 「ダストを 16 マス伸ばしたら、どこまで光る？」）。
