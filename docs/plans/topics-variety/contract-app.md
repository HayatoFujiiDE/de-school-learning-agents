既存 4 題材のデータと挙動は変えない。3 題材を足す。各題材は既存と同じ形（`THEME` / `VARIANT` / `extCards` / `MD.result` / `MD.code` / `MD.desc` / 線画 / `MD.artMarks` / `MD.testReply` / `MD.photoArt`）を全部持つ。未知の題材 id で別題材の文や `NaN` が出ない（既定の落ち先に頼らず、3 題材それぞれの分岐を明示する）。

**stop（コマ撮りの動画）**

```
sample 'walk' / ideas ['clay','brick','draw'] / capIdea 'clay' / variants ['walk','clay','brick','draw']
topic  ['コマ撮りの動画', 'コマどりの動画']
effect ['動画の動き', '動画のうごき'] / aim ['動き', 'うごき']
changeable [['コマの数','コマの数'], ['1 秒のコマ数','1 びょうのコマ数']]
params
  frames: label ['コマの数','コマの数'] min 0 max 4 def 2  vals [6,8,12,18,24]  names '6 コマ' … '24 コマ'
  fps:    label ['1 秒のコマ数','1 びょうのコマ数'] min 0 max 3 def 1  vals [4,6,8,12]  names ['1 秒に 4 コマ','1 びょうに 4 コマ'] …
stepBase ['コマの数を変える', '1 秒のコマ数を変える', '撮る物を決める']
extSteps ['写真を入れる', 'コマを足す']
find [{frames:3,fps:1}, {frames:1,fps:2}]
```

| variant | title（中） | values | step3 | 結果の主語 |
|---|---|---|---|---|
| walk | コマ撮りの短い動画 | frames 2, fps 1 | — | 人形が歩く動画 |
| clay | 粘土が形を変える動画 | frames 2, fps 1 | 粘土の色を決める | 粘土が形を変える動画 |
| brick | ブロックの車が走る動画 | frames 3, fps 2 | 道を作る | ブロックの車が走る動画 |
| draw | 絵が動き出す動画 | frames 1, fps 1 | 最初の絵を描く | 絵が動き出す動画 |

- 計算: `F = vals[frames]`、`P = vals[fps]`、`S = round(F / P × 10) / 10`。
- `MD.result`: `{主語} · {F} コマ ÷ 1 秒に {P} コマ = {S} 秒`
- `MD.code`: `{F} コマ ÷ {P} コマ/秒 = {S} 秒`
- `MD.desc`: `{F} コマ · 1 秒に {P} コマ`
- 線画: 上にコマの枠が `F` 個並ぶ（1 行に入らなければ 2〜3 行。枠の中の主役の位置や形が、コマごとに少しずつ変わる）。下に時間の線（長さが `S` に比例・1 秒ごとの目盛り）。`MD.artMarks` = `{frames: F, secs: S}`。
- `MD.testReply`: frames → effect `動画の長さ` / aim `長さ` / how 増 `動画が長くなった`・減 `動画がみじかくなった`。fps → effect `動きのなめらかさ` / aim `なめらかさ` / how 増 `なめらかに動いた`・減 `カクカク動いた`。
- `extCards.stop`
  - calc「コマの計算」: `12 コマ ÷ 1 秒に 6 コマ = 2 秒` / `10 秒にするには 60 コマ` / `1 コマで 5 mm 動かすと、60 コマで 30 cm`。alt「コマの計算（1 秒に 12 コマ）」: `12 コマ ÷ 1 秒に 12 コマ = 1 秒` / `10 秒にするには 120 コマ` / `1 コマで 2.5 mm 動かすと、120 コマで 30 cm`
  - steps「撮り方の手順」: `1. カメラを動かないように固定する` / `2. 少し動かして 1 枚撮る` / `3. 12 回くり返して、つなげて見る`。alt「撮り方の手順（形を変える）」: `1. カメラを動かないように固定する` / `2. 粘土を少しつまんで 1 枚撮る` / `3. 12 回くり返して、つなげて見る`
  - cmd `{variant:'clay', values:{frames:2, fps:2}}`

**ath（マイクラのアスレチック）**

```
sample 'jump' / ideas ['slime','piston','ice'] / capIdea 'slime' / variants ['jump','slime','piston','ice']
topic  ['マイクラのアスレチック', 'マイクラのアスレチック']
effect ['コースの手ごたえ', 'コースの手ごたえ'] / aim ['手ごたえ', '手ごたえ']
changeable [['足場のあいだ','足場のあいだ'], ['足場の数','足場の数']]
params
  gap:   label ['足場のあいだ','足場のあいだ'] min 1 max 4 def 2
  count: label ['足場の数','足場の数'] min 3 max 8 def 5
stepBase ['足場のあいだを変える', '足場の数を変える', 'ゴールを置く']
extSteps ['写真を入れる', 'ギミックを足す']
find [{gap:3,count:6}, {gap:1,count:8}]
```

| variant | title（中） | values | step3 | ギミックの足場 | ブロック id |
|---|---|---|---|---|---|
| jump | マイクラのアスレチック | gap 2, count 5 | — | なし | `stone` |
| slime | スライムで跳ねるコース | gap 3, count 5 | 跳ねる高さを試す | 跳ねる足場 | `slime_block` |
| piston | ピストンで動く足場のコース | gap 2, count 6 | 動くタイミングを決める | 動く足場 | `piston` |
| ice | 氷ですべるコース | gap 2, count 4 | 止まる場所を作る | すべる足場 | `packed_ice` |

- 計算: `n = count`、`g = gap`、ギミックの足場の数 `k = floor(n / 2)`（jump は 0。2 個目・4 個目…がギミック）、コースの長さ `L = n + g × (n − 1)`。
- 手ごたえ（このモックでの目安。ゲームの事実としては書かない）: g=1 `かんたん` / 2 `ふつう` / 3 `むずかしい` / 4 `とてもむずかしい`。
- `MD.result`: jump `足場 {n} 個 · あいだ {g} ブロック · {手ごたえ}`。ほか `足場 {n} 個（{ギミックの足場} {k} 個）· あいだ {g} ブロック · {手ごたえ}`
- `MD.code`: 足場ごとに `/setblock ~{x} ~ ~ minecraft:{id}`（`x = i × (g + 1)`、i は 0 から。ギミックの足場だけ variant の id、ほかは `stone`）。先頭 3 行を出し、4 個目以降があれば最後の行に `…`。
- `MD.desc`: `足場 {n} · あいだ {g}`
- 線画: 横から見たコース。左にスタートの旗、右にゴールの旗。足場 `n` 個が `g` に比例した間隔で並ぶ。ギミックの足場は橙で、種類ごとに形を変える（跳ねる = 上向きの矢印 / 動く = 左右の矢印 / すべる = 斜めの線）。`MD.artMarks` = `{count: n, gap: g, gimmick: k}`。
- `MD.testReply`: gap → effect `とぶ距離` / aim `距離` / how 増 `足場がはなれた`・減 `足場が近くなった`。count → effect `コースの長さ` / aim `長さ` / how 増 `コースが長くなった`・減 `コースがみじかくなった`。
- `extCards.ath`
  - calc「コースの長さ」: `足場 5 個 · あいだ 2 ブロック` / `5 + 2 × 4 = 13 ブロックの長さ` / `足場を 8 個にすると 22 ブロック`。alt「コースの長さ（あいだ 3）」: `足場 5 個 · あいだ 3 ブロック` / `5 + 3 × 4 = 17 ブロックの長さ` / `足場を 8 個にすると 29 ブロック`
  - steps「コースの手順」: `1. スタートの足場を置く` / `2. あいだをあけて、次の足場を置く` / `3. 最後にゴールの目印を置く`。alt「コースの手順（ギミック）」: `1. スタートの足場を置く` / `2. 2 個目ごとにスライムブロックを置く` / `3. だれかに遊んでもらって、手ごたえを聞く`
  - cmd `{variant:'slime', values:{gap:3, count:5}}`

- `MD.result`: `{n} 場面の物語 · {語り手の名前} · 山場は {k} 場面目`

- `extCards.story`
  - calc「場面の割りふり」: `4 場面: はじまり 1 · できごと 2 · おわり 1` / `1 場面 200 字なら、全部で 800 字` / `山場は 3 場面目`。alt「場面の割りふり（6 場面）」: `6 場面: はじまり 1 · できごと 4 · おわり 1` / `1 場面 200 字なら、全部で 1200 字` / `山場は 5 場面目`

  - cmd `{variant:'mystery', values:{scenes:5, voice:1}}`

- 見出しと 1 文は既存のまま。

  - まとめて: 展示の一覧の上の切替「完成にした作品を、自動で展示に出す」（初期は切）。入れると、完成（`status: 'done'`）の作品がこれから残すものも含めて展示に並ぶ。ただし写真から入れた作品（`from: 'capture'`）は自動では出さない（顔や名前が写っていないかを本人が見てから、1 つずつ出す）。切替の下に 1 行「写真から入れた作品は、1 つずつ出してね」。入れた時にトースト「完成にした作品が展示に並ぶよ」。作品ごとに「展示から外す」をした作品は、切替が入っていても出さない。
- 試作（`trial`）は自動では出さない（1 つずつなら出せる）。
- 展示に出るのは: 作品の絵（写真・線画）・題・呼び名・種類・本人が書いた「気に入っているところ」「工夫したところ」。「作ってきた流れ」とバディの見立ては出さない。バディが関わった作品には出所の印「バディと作った」を付ける。
- 写真から入れた作品を出す時は、確定の前に 1 文「写真に、人の顔や名前が写っていないか見てね」。
- 外す → 一覧から消える。トースト「展示から外した」+「元に戻す」。
- 作品そのものを「作品から外す」した時は、展示からも消える。

- 種類のチップで絞る: 「すべて」+ 並んでいる作品の種類（マイクラ / プログラミング / ものづくり / デジもの / 画像・動画 / 絵 / 文章）。並びは新しい順だけ（人気順を作らない）。

### AG-4 詳細・反応・ひとこと

- 戻る「作品展示」/ 大きい絵 / 題 / 呼び名 / 種類 / 気に入っているところ・工夫したところ（書いてあるものだけ）/ 出所の印。自分の作品には「作品のページで開く」リンク。
- 反応ボタン 3 つ（押すと入る・もう一度で外れる。`aria-pressed`）: 「ここが好き」「どうやったの？」「まねしてみたい」。押した人の呼び名が、ボタンごとにチップで並ぶ（数字にしない）。自分の作品には反応ボタンを出さず、届いた反応だけ見える。
- ひとこと（自由文 1〜80 字。字数は入力欄も保存もコードポイントで数える）: 入力 + 「送る」。送ると「AI が先に読んでいるよ」（1 秒ほど。reduced-motion でも待ちは同じ）→ 番人の結果で分かれる:
  - 届く → スレッドに呼び名・時刻つきで出る。トースト「届いたよ」。
  - 届けない → スレッドには出ず、本人にだけ「このひとことは、サポーターが先に読むことになったよ」と出る（本文は本人に見える・「取り消す」ができる）。
- 自分のひとことは「取り消す」ができる（トースト + 元に戻す）。
- 番人（モックの決定論。純関数 `G.guard(text)` → `'ok' | 'hold'`）: `hold` にするのは (a) `gallery-data.js` の語の一覧（人を傷つける言い方の短い一覧。実装担当が 15 語ほど置く）を含む (b) 7 けた以上続く数字 (c) `http`・`@`・「住所」「電話」「LINE」を含む (d) 同じ文字が 8 回以上続く。それ以外は `ok`。本番では AI の番人が読む、という説明を画面に出さない（画面の文言は上の 2 つだけ）。
- スレッドに返事はできる（作者も見ている人も、同じ入力から。番人も同じ）。

### AG-5 声かけ → いっしょに作る

## レビューへの裁定（2026-11-06。Astra medium ×2 = §AE / §AF・§AG。どちらも BLOCKING なし・REVISE）

直す（実装）:
- 保存に失敗した時は、移動・成功のトースト・切替をしない（状態を戻して `save_fail`）: 提案の「これで始める」/ 見本・提案の入れ替え / 対話のお題の「作ってみる」「バディと話す」「とっておく」/ 入口を開いた記録。
- 見本の作品の追加（AE-6）: 活動・作品・番号の保存が全部成功した時だけ番号を進める。
- あしあとの「もう一度試す」で、提案から作った活動の `projectId` と写真のカテゴリを引き継ぐ。
- 対話のお題から作った活動: 「必要な物をまとめて」を出さない（必要な物の欄が無いため）。写真のダミーはお題の絵。
- 展示の種類: 提案から作った作品は提案のカテゴリ。
- 考えの id・約束の id: 既にある id と重ならない採番 / 空の id は読み込み時に捨てる。
- ひとこと: 送信待ちの間は、どの作品の「送る」も disabled にする。
- フォーカス: 考えの保存の失敗の後 / 古い考えを外して元に戻した後。
- 展示の絵: 保存された作品の絵の形が違う時は、種類の線画に替える（例外で止めない）。
- 3 題材（stop / ath / story）の計算: 値が欠けている・範囲の外の時は、その題材の既定値で計算する（`NaN`・`undefined`・`{F}` を出さない）。
- `tools/gen-thumbs.mjs`: エラーの時に出すのは、決まった分類の文だけ（API が返した文字列・例外の名前をそのまま出さない）。
- `tools/today-test.js`: 題材（stop / ath / story）が `MD.THEMES` にあることを必須に戻す。

契約の方を直した（上の本文に反映済み）:
