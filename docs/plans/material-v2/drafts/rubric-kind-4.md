# 採点表（型 4: 動かせるもの）

- `parts/<part_id>/app.html` が 1 ファイルで完結し、`<script src`, `<link `, `fetch(`, `import ` を含まない
- 操作 1 つ（スライダー・ボタン・クリックのどれか）で見た目が変わる
- どの操作も「さわると何が分かるか」が本文の内容に結びついて 1 文で言える。速さや数を変えるだけで分かることが増えない操作（飾りの操作）が無い。操作の前に問い、操作の後に何が起きたかの一言がある
- 動きを見ると分かる題材（体の中の流れ・天体や粒の動き・波・力と運動など）では、canvas に奥行きのある動く絵がある（遠くは小さく、近くは大きく、丸みに明暗）。平たい図形を並べただけの画面になっていない
- 画面の中に、何を操作すると何が変わるかの 1 文がある
- 幅 390px でも横にはみ出さない（CSS の max-width と相対単位で組む）
- material.json の runtime_check に「どう操作して」「何が起きれば正しいか」が書かれ、selfcheck.md に自分で確かめた結果がある
- 画面の中の文言は中学 1 年生が読める文で、本文（body.md）と矛盾しない。目標の言い回し（目標・ねらい・めあて・学ぼう など）が無い
